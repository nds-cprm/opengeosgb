{% load i18n %} {% comment %} Tradução dos textos padrão do componente de seleção (react-select v1) do client. Os filtros por facet da barra lateral do catálogo (categoria, palavra-chave, região, proprietário, grupo, escala) são montados pelo client a partir da API de facets, sem placeholder, e o componente usa os textos padrão, fixos em inglês ("Select...", "No results found"...). O localConfig não alcança esses campos. Aqui, os textos padrão são trocados no DOM pela tradução do Django; só o texto exatamente igual ao padrão em inglês é trocado, e no inglês nada muda. Incluído em geonode-mapstore-client/snippets/head.html. Ao atualizar o client, conferir se ainda é necessário. {% endcomment %} {% trans "Select..." as s_select %}{% trans "No results found" as s_noresults %}{% trans "Loading..." as s_loading %}{% trans "Type to search" as s_typetosearch %}
